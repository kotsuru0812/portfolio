# Hobby 運用ガイド

トップページ下部の Hobby セクション（和菓子・スイーツ写真グリッド）の更新手順です。

## 関連ファイル

| ファイル | 役割 |
|----------|------|
| `src/components/Home/images.ts` | 画像パス・alt・width/height の一覧 |
| `src/components/Home/Hobby.tsx` | グリッド表示・ライトボックス |
| `public/hobby/` | 画像ファイル本体 |

## 画像の差し替え手順

### 1. 画像を `public/hobby/` に配置

例: `dsc02499.png`（拡張子は `.png` で統一）

### 2. `images.ts` を編集

`src/components/Home/images.ts` の配列を更新します。配列の順序が **画面上の表示順** になります。

```ts
export const images: ImageProps[] = [
  { src: "/hobby/dsc02499.png", alt: "もらい水", width: 1024, height: 682 },
  // ...
];
```

| プロパティ | 説明 |
|-----------|------|
| `src` | `/hobby/` からのパス（先頭スラッシュ必須） |
| `alt` | アクセシビリティ用の説明（作品名・銘柄名など） |
| `width` / `height` | 実画像のピクセル数（Next/Image 用） |

### 3. 旧ファイルの削除

参照がなくなった画像は `public/hobby/` から削除してリポジトリを整理します。

### 4. 確認

```bash
npm run dev
```

トップページの Hobby グリッドと、画像クリック時のライトボックス（拡大・切り替え）を確認します。

## ライトボックスの挙動

- パッケージ: `react-simple-image-viewer`
- グリッドの任意の画像をクリックすると、全枚を拡大表示
- 閉じる: 外側クリックまたはビューアの閉じる操作

Portfolio 詳細のカルーセルとは別実装です。Hobby にカルーセル UI はありません。

## 推奨画像サイズ

| 項目 | 値 |
|------|-----|
| 解像度 | 1024×682 前後（3:2 横長） |
| 形式 | PNG |
| 枚数 | 現在 6 枚（配列長を増減すれば枚数変更可能） |

実寸の確認（macOS）:

```bash
sips -g pixelWidth -g pixelHeight public/hobby/ファイル名.png
```

## レイアウト

`Hobby.tsx` のグリッド:

- スマホ: 2列
- 大画面: 3列
- 各画像は `width` / `height` から算出した `aspectRatio` で表示

画像枚数を増やす場合は `images.ts` にエントリを追加するだけで、グリッドは自動で行が増えます。
